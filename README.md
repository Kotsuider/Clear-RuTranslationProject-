# Проект перевода Clear на русский язык

## Общие сведения

Перевод делается c помощью gemini с последующей редактурой.
⚠️ **Внимание:** вн может вести себя нестабильно и вылетать. Если встретили такую проблему, то пришлите точное место вылета в `issues`. 
Перед каждым запуском нужно прожимать unlock_config.bat
Запускать с эмулятором локали.

## Установка
1. Скачайте
2. Скопируйте папку `rld` и переименуйте копию в `rld_backup`,
2. Распакуйте архив в папку, установите шрифт
3. Профит!
